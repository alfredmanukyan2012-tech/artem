Cartoon GUI Smooth — клиентский мод Fabric для Minecraft 1.21.1

Что делает
- кнопки во всех меню появляются каскадом с лёгкой пружиной, при наведении мягко увеличиваются;
- окна инвентаря/сундуков/верстака открываются с пружинным масштабом и подъёмом;
- рамка выбранного слота хотбара плавно «едет» между слотами с лёгким перелётом.

Как собрать (нужен JDK 21)
1) Установи Gradle 8.10+ (или открой папку в IntelliJ IDEA — она сама всё подтянет).
2) В папке проекта: gradle build
3) Готовый мод: build/libs/cartoon-gui-smooth-1.0.0.jar -> положи в папку mods.

Без установки: залей папку в репозиторий GitHub — workflow в .github/workflows соберёт jar сам
(вкладка Actions -> скачать artifact).

Нужно: Fabric Loader 0.16+, Fabric API для 1.21.1.
ВАЖНО: OptiFine с Fabric 1.21.1 не работает; вместо него Sodium + Iris.
